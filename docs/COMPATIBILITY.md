# URL download and caption compatibility

Paste a video link into the **URL** field on PineFetch's Download screen. PineFetch passes it to yt-dlp. The platforms below have extractors in yt-dlp 2026.08.19; individual videos may still be unavailable. See yt-dlp's [full supported-sites list](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md).

| Source             | Example URL                                                       | Post caption saved                                                          |
| ------------------ | ----------------------------------------------------------------- | --------------------------------------------------------------------------- |
| YouTube            | `youtube.com/watch?...`, `youtube.com/shorts/...`, `youtu.be/...` | Yes, when **Save post captions** is enabled and the video has a description |
| TikTok             | `tiktok.com/@user/video/...`, `vm.tiktok.com/...`                 | Yes, when **Save post captions** is enabled and the video has a description |
| Instagram          | `instagram.com/p/...`, `instagram.com/reel/...`                   | Yes, when **Save post captions** is enabled and the video has a description |
| Facebook           | `facebook.com/...`, `fb.watch/...`                                | Yes, when **Save post captions** is enabled and the video has a description |
| Twitch             | `twitch.tv/...`                                                   | No                                                                          |
| X                  | `x.com/...`, `twitter.com/...`                                    | No                                                                          |
| Reddit             | `reddit.com/r/.../comments/...`                                   | No                                                                          |
| Snapchat Spotlight | `snapchat.com/spotlight/...`                                      | No                                                                          |
| Pinterest          | `pinterest.com/pin/...`                                           | No                                                                          |
| Bluesky            | `bsky.app/profile/.../post/...`                                   | No                                                                          |
| Tumblr             | `tumblr.com/...`                                                  | No                                                                          |
| LinkedIn           | `linkedin.com/posts/...`                                          | No                                                                          |
| VK                 | `vk.com/video...`                                                 | No                                                                          |
| 9GAG               | `9gag.com/gag/...`                                                | No                                                                          |
| Vimeo              | `vimeo.com/...`                                                   | No                                                                          |
